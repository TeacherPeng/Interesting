# 2026-11-21 工作日志

## 项目框架调研
- ImageProcessing 项目含两代工程：原 `ImageProcessing` 是 .NET Framework 4.8（WPF + 内嵌 Emgu.CV 源码）；`ImageProcessing.net` 是 .NET 10（net10.0-windows10.0.17763.0，SDK 风格）。
- 本机 SDK 为 .NET 11.0.100。

## .NET 10 下 OpenCV 选型结论
- OpenCvSharp5 最新稳定 5.1.0.20261115（基于 OpenCV 5.1.x），主命名空间仍为 `OpenCvSharp`，包名改为 `OpenCvSharp5.*`。
- 迁移要点：4→5 包/命名空间改名（`OpenCvSharp4.WpfExtensions`→`OpenCvSharp5.WpfExtensions`，`Extensions`→`GdipExtensions`）；`CvXxx` 门面类折叠为 `Cv2.Xxx`；Mat 的 fluent 实例方法移除，改用 `Cv2.Xxx(mat,...)`；MatExpr 部分运算符重载移除（如 `double - MatExpr`、`Mat - int` 不可用），改用 `Cv2.Subtract/Add/Divide` 或 `ConvertTo` 的 alpha/beta。
- Emgu.CV 最新稳定 5.0.0.6584（OpenCV 5.0），5.1.0 已上 wiki 但未上 NuGet 且转向 .NET 11。

## 完成：ImageProcessing.net 接入 OpenCvSharp 5 并重写全部 Processing_*
- 包：`OpenCvSharp5.Windows` 5.1.0.20261115（all-in-one，含 WpfExtensions/GdipExtensions/runtime.win）。
- 架构改造：`Processing` 基类由 byte[] raw data 改为基于 `Mat` —— 用 `BitmapSourceConverter.ToMat` / `ToMat` 前后转换，统一转 3 通道 BGR；`protected abstract Mat ProcessImage(Mat)`。
- 重写 14 个算法：Border/Negative/HalfSize/IncBrightness/IncConstrast/IncSaturation/DarkChannel/Dehaze/SmoothGaussian/SmoothBlur/SmoothMedian/SmoothBilatral/Erode/Sobel。
- 新增 `Dehaze.cs`（OpenCvSharp 版去雾，原 Method_Dehaze.cs 的移植，保留 airlight 平滑状态）。
- `ImageProcessingModel` 注册全部 14 个算法。
- 验证：`dotnet build` 0 警告 0 错误；原生 `OpenCvSharpExtern.dll` 已部署到输出目录 runtimes/win-x64/native。
- 数值语义说明：亮度/对比度用 ConvertTo 的 alpha/beta+CV_8U saturate；饱和度用 CV_32F 通道分离线性拉伸；Sobel 用 CV_16S+ConvertScaleAbs；去雾用 Cv2 算术方法避免 MatExpr 运算符限制。
