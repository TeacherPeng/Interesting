# Claim

一款基于用WorkBuddy生成的 WPF / C# 的「围地」街机游戏，玩法参考经典 Qix。在边框上巡航、切入空地画出轨迹、回到边框结算填色，一寸寸把场地圈成自己的领地——同时要躲开不断扫动的激光。

## 玩法

- **巡航**：圆点沿边框（空地边界）匀速移动，初始边框是正方形场地。
- **切入与围地**：朝空地方向按键，圆点离开边框开始画轨迹；轨迹回到边框时结算，围出的区域被填色，这条轨迹随即成为新的边框。被围掉的旧边框段退出，圆点可沿新边框继续走、也可再次切入。
- **轴向轨迹**：圆点的运动只允许水平或垂直，不产生斜线；轨迹在中途的转向处会被如实记录，围出的色块边缘因此都是横平竖直的。
- **禁止掉头**：未封闭的轨迹上不能原路倒回（否则忽略反向键）；但在边框上可按反向键掉头。刚切入的一小段"起笔通道"内按纯反向键可撤销这一笔，退回原位。
- **通关**：已围面积占比达到 96% 即通关；若边框上再也找不到能切入的空地，则只能重开。

## 扫描线（核心威胁）

- 场内有 **5 根红色扫描线**，共用同一个运动中的交点（枢纽），呈扇形展开；枢纽在场内游走、碰边界反弹、遇色块沿墙滑行。
- 每根线都有自己的朝向：整体一起旋转的同时，各线还有独立的限幅摆动。5 根线**相邻夹角之和恒不超过 60°**，既各有姿态又永不重合或发散。
- 每根线取穿过枢纽、落在空地里的那段弦，**两端精确压在边框上**；已填色块像墙一样把激光截断，不会被穿过。
- **判负规则**：圆点一旦离开边框，只要扫描线扫到它**已经画出的任意一段轨迹**（不只是圆点当前位置），游戏立即结束。回到边框的那一子步不算。
- 圆点在边框上巡航时，即使被扫描线压过也不判负。

## 操作

| 按键 | 作用 |
| --- | --- |
| 方向键 / `W` `A` `S` `D` | 控制方向；朝空地按可切入，沿边框按可巡航、掉头 |
| `Esc` | 暂停 / 继续 |
| `R` | 重新开始 |
| `Enter` | 死亡或通关后重新开始 |

窗口失焦时自动暂停，回到窗口继续。

## 构建与运行

需要 .NET 11 SDK（目标框架 `net11.0-windows`，启用 WPF）。

```bash
dotnet build WeiDi.csproj
```

运行程序：

```bash
dotnet bin/Debug/net11.0-windows/WeiDi.dll
```

带命令行参数的两个离线模式（不打开窗口，跑完自动退出）：

```bash
# 无窗口规则自检，结果写入 bin/Debug/net11.0-windows/_selftest.log
dotnet bin/Debug/net11.0-windows/WeiDi.dll --selftest

# 离线渲染两张核对画面 _shot_1.png / _shot_2.png
dotnet bin/Debug/net11.0-windows/WeiDi.dll --shot
```

未捕获异常会追加到运行目录下的 `crash.log`。

## 代码结构

逻辑坐标固定为 900×900，与窗口尺寸无关；窗口只影响渲染缩放。物理采用固定步长（1/240 秒）。

| 文件 | 职责 |
| --- | --- |
| `App.xaml.cs` | 应用入口、命令行参数分发、异常日志 |
| `MainWindow.xaml.cs` | 主窗口、键盘消息转发 |
| `Game/GameConfig.cs` | 全部可调参数集中在这里（速度、阈值、扫描线参数等） |
| `Game/GameSession.cs` | 一局游戏的状态与推进逻辑：边框巡航、切入、轨迹、回框填色、判负 |
| `Game/Boundary.cs` | 边框折线：弧长定位、法向、切入/闭合、改道 |
| `Game/PaintGrid.cs` | 栅格化的填色区域，负责面积统计与碰撞查询 |
| `Game/Arena.cs` | 场地常量与坐标辅助 |
| `Game/ScanLines.cs` | 共点扇面扫描线的运动、求弦与碰撞检测 |
| `Game/SelfTest.cs` | 无窗口规则自检、离线截图 |
| `View/GameView.cs` | 渲染与输入：边框、轨迹、色块、扫描线、HUD、死亡/暂停界面 |
| `View/Palette.cs` | 配色 |

调玩法手感只需修改 `Game/GameConfig.cs` 中的常量。
